Device & Browser Support

Recommended OS, browser and device coverage for QA testing.

Market share and device support can differ between US and Worldwide. To determine what should be supported and what can be dropped, please see the Market Share page.

Data last updated October 28, 2026.

Rules of thumb

  • Default browsers only

    On mobile, we usually support only each device's default, pre-installed apps and settings. On iOS that's Safari. Chrome isn't installed by default, but it should still be checked because of its popularity.

  • Latest versions

    Browsers usually auto-update, so only the latest version is supported. Safari updates with the OS, so it should be tested on each supported OS version.

  • Samsung Internet on Samsung

    Samsung devices ship with both Chrome and Samsung Internet, so test both. Samsung Internet is supported only on Samsung devices.

  • Social in-app browsers

    If a project targets social media, the page must work in each app's in-app browser (Facebook, Twitter, Instagram and so on), since those apps open links there by default.
