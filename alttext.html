Accessibility

Alt Text Overlay

A bookmark tool that surfaces the alt text on every image on the page you're testing, so missing alt text stands out at a glance.

WCAG 2.2 AA: alt text requirements

Alt text is covered by Success Criterion 1.1.1 Non-text Content (Level A, so required for AA). Every image that conveys meaning needs a text alternative that serves the same purpose. Images that are purely decorative must be marked so screen readers skip them.

Informative images

Photos, illustrations and icons that add information. The alt text describes what the image conveys in this context, not every visual detail.

alt="Two developers reviewing a design on a laptop"

Functional images

Images inside a link or button, and image buttons. The alt text says where the link goes or what the button does, not what the picture looks like.

alt="Search" on a magnifying-glass button

Decorative images

Images that add nothing a user would miss: flourishes, background textures, or a photo that repeats nearby text. Mark them with an empty alt, or move them to CSS.

alt="" (empty, not missing)

Images of text

The alt text contains the same words as the image. WCAG also asks for real text instead of images of text wherever possible (SC 1.4.5 Images of Text, Level AA).

alt="Spring sale: 20% off everything"

Complex images

Charts, diagrams and maps. Give a short alt text naming what the image is, plus a full description or data table nearby or linked from it.

alt="Bar chart of sales by region, described below"

Missing alt is a failure

An image with no alt attribute at all fails 1.1.1. Screen readers often fall back to reading the file name, such as "IMG underscore 4021 dot jpeg".

Every <img> needs an alt, even if it is empty.

Things to look for when checking alt text

  • Alt text that starts with "Image of" or "Picture of". Screen readers already announce it as an image, so this should be removed.
  • Alt text that is a file name (such as "IMG_4021.jpg") or a vague word on its own, like "image", "photo" or "banner".
  • Alt text that repeats the text right next to the image. The image should usually be marked decorative with alt="" instead.
  • Images that contain words. Check that the alt text includes those words.

Get the bookmarklet

Alt Text Overlay

Drag this button to your bookmarks bar.

  1. Show your bookmarks bar. Press Ctrl+Shift+B (Windows) or ⌘+Shift+B (Mac).
  2. Drag the Alt Text Overlay button onto the bookmarks bar.
  3. Open the page you're testing and click the bookmark. Every image gets a label, and a summary appears in the bottom-right corner.
  4. Click the bookmark again (or the × on the summary) to hide the labels.

What the colors mean

  • Alt text: A team meeting around a tableThe image has alt text (or another accessible name). Check that it's accurate.
  • Missing alt textNo alt attribute or accessible name. This fails WCAG 1.1.1.
  • No alt text needed (marked decorative: alt="")Marked as decorative, so screen readers skip it. Check that it really is decorative.

Good to know

! The overlay can't judge whether alt text is accurate, or whether an image marked decorative really is. It only shows what's there. A person still needs to check each image.

  • It covers <img>, image buttons and anything with role="img". CSS background images and inline SVGs without role="img" aren't labelled.
  • Images that load after you turn it on (for example, while scrolling) aren't labelled. Click the bookmark twice to refresh.
  • Works in desktop Chrome, Edge, Firefox and Safari. Bookmarklets aren't practical on phones.
