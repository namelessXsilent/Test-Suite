About the AI Payload Library

Default collections (SQL Injection, XSS, the AI Agent Testing sets, and so on) are built into the site and always available to everyone.

Collections and payloads you create are saved in this browser's local storage. That means they:

  • persist across refreshes and restarts on this browser,
  • are private to you — other visitors don't see them,
  • and are lost if you clear this browser's site data (or use private / incognito mode, or switch browsers or devices).

Export downloads all of your custom collections and additions as a single JSON file — use it as a backup or to share your set with someone else. Import reads such a file back in and merges it with what you already have (nothing is overwritten unless a name matches exactly).
