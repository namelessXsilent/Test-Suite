QA Testing Resources

Tools and references for use while testing.

WCAG 2.2 · AA

Text Contrast Checker

Upload a screenshot or mockup — OCR finds every text block, auto-detects the text and background colors and font size, then runs WCAG 2.2 AA contrast checks. Edit any value inline to recheck, with a suggested nearest-passing color for each failure.

WCAG 2.2 · UI

Button Contrast Checker

Upload or paste a button screenshot; it detects the label with OCR plus the text color, button fill and page background. Checks text-vs-button (SC 1.4.3) and button-vs-page (SC 1.4.11) at AA, with inline edits, large-text detection and suggested fixes.

Red-Team · Web

AI Payload Library

A searchable library of adversarial test payloads — SQL injection, XSS, path traversal, prompt injection, jailbreaks, plus Unicode, length and number edge cases. One click copies a payload to the clipboard, and you can save your own.

Device & Browser Support

Recommended QA coverage: the operating systems, browsers and versions to test on desktop, tablet and mobile, the supported iOS and Android devices, and the rules of thumb behind them, with browser market share for context.
