Design Grid Overlay

A bookmark tool that lays an 8px baseline grid and a responsive 12-column layout over any page, so you can check spacing and alignment against the design.

What to check with the grid

Vertical spacing

Gaps between sections, cards, headings and paragraphs land on the baseline grid, usually in multiples of 8px (8, 16, 24, 32…).

Column alignment

Content edges line up with the column edges, and elements span the number of columns the design shows.

Gutters and margins

The space between columns and at the page edges matches the design, and stays consistent across the page.

Breakpoints

Resize the window: the layout should switch column counts where the design does, without content spilling past the margins.

Max width

On wide screens the content stops growing at the design's maximum width and stays centered.

Repeated components

The same card, button or form field has the same padding and height everywhere it appears.

Get the bookmarklet

Design Grid Overlay

Drag this button to your bookmarks bar.

  1. Show your bookmarks bar. Press Ctrl+Shift+B (Windows) or ⌘+Shift+B (Mac).
  2. Drag the Design Grid Overlay button onto the bookmarks bar.
  3. Open the page you're testing and click the bookmark. The grid appears, with a control panel in the bottom-right corner.
  4. Match the design: switch Layout to Custom and enter the columns, gutter, margin and max width from the Figma layout grid.
  5. Click the bookmark again (or the × on the panel) to hide it.

What you'll see

  • Blue lines: the baseline grid. A faint line every 8px and a stronger line every 32px. It scrolls with the page.
  • Red columns: the layout columns, with gutters between them. They stay fixed to the window as you scroll.
  • Viewport 1440 px · Desktop: 12 columns…Panel readout: the window width, the layout in use, and the exact column width.

Good to know

! The Auto layout is a common default, not your project's design. Every design system sets its own columns, gutters and breakpoints. Switch to Custom and copy the values from the Figma layout grid before reporting misalignment.

  • The overlay is for spotting problems by eye. Use the browser's developer tools or Figma's Inspect panel to confirm exact pixel values.
  • Settings reset when you turn the overlay off. It doesn't save anything to the site you're testing.
  • The overlay sits on top of the page but doesn't block clicks, so you can keep using the site with it on.
  • Works in desktop Chrome, Edge, Firefox and Safari.
